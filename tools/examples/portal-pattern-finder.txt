# Portal Pattern Finder: broken-portal shapes in cave air, and shapes that must not count. Expect a chat line after each
# of P1 (x-plane 2x3), P2 (z-plane 2x3), P3 (frame-sized 4x5 without corners), P4 (across a chunk border), P5 (inside a
# kept obsidian frame) and P6 broken (a lit portal, once broken, not while lit). None after N1 (one wide), N2 (two
# thick), N3 (no cave air) or N4 (too wide). Empty frames out in the open, no cave air: a line after F1 (x), F2 (z); none
# after F3 (a block missing), F4 (one wide) or F5 (a frame with a stone block in it).
# Setup:  python tools/testcfg.py setup portal-pattern-finder notify=true
# Run:    sh tools/run-test.sh tools/examples/portal-pattern-finder.txt
# Restore: python tools/testcfg.py restore
title 40
world

cmd gamerule advance_time false
cmd time set 6000
cmd kill @e[type=!player]

wait 10

wait 10
